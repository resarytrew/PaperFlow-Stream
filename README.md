# PaperFlow Stream

Локальная система потокового сканирования письменных ответов учеников:
веб-камера над партой → автоматический захват листа → выравнивание и
улучшение изображения → идентификация по QR-коду → цифровой архив →
распознавание рукописного текста → проверка учителем → экспорт.

Все данные (фото листов, база, результаты) остаются на компьютере учителя.

## Быстрый старт

Требуется Python 3.11+ (и Node.js LTS — только при первом запуске, для сборки интерфейса).

**Windows** — двойной клик по `run.bat`.

**Linux / macOS:**

```bash
./run.sh
```

Скрипт сам создаст окружение, соберёт интерфейс и откроет
<http://localhost:8000>. Все последующие запуски — те же команды, стартует
за пару секунд.

### Ручной запуск (для разработки)

```bash
# бэкенд
# Важно: установку зависимостей выполняйте из каталога backend —
# requirements.txt содержит локальный headless-shim для OpenCV/RapidOCR.
cd backend
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --reload --port 8000

# фронтенд (dev-сервер с горячей перезагрузкой, проксирует /api)
cd frontend
npm install
npm run dev            # http://localhost:5173
```

Собранный интерфейс (`frontend/dist`) автоматически раздаётся бэкендом —
в «боевом» режиме нужен только один процесс uvicorn.

## Типовой сценарий работы

1. **Классы и задания** — заведите класс, вставьте список учеников
   (`ID;Фамилия;Имя` построчно), создайте задание.
2. **Бланки** — сформируйте PDF с QR-кодами и распечатайте (масштаб 100%).
3. **Калибровка** — 4 шага: проверка камеры → съёмка пустого фона →
   определение рабочей зоны по бланку → тестовый захват.
4. **Сессия** — создайте сессию и подавайте листы под камеру по одному.
   Экран подсказывает крупными надписями («ПОЛОЖИТЕ ЛИСТ», «НЕ ДВИГАЙТЕ»,
   «ЛИСТ ПРИНЯТ»), приём/брак дублируется звуком. Пробел — старт/пауза.
5. **Проверка** — вкладки очередей (уверенные, требующие проверки, без QR,
   пустые…), исправление распознанного текста, привязка листов без QR.
6. **Экспорт** — CSV / JSON / XLSX / ZIP с изображениями.

## Тесты

```bash
cd backend && .venv/bin/python -m pytest
```

160+ тестов: CV-ядро (детекция, геометрия, качество, QR, окклюзия),
сквозные интеграционные сценарии API/WebSocket на синтетических кадрах
(захват листа, дубликаты, нечитаемый QR, OCR-очередь, экспорт) и smoke-test
миграций Alembic для чистой локальной базы.

## Ограничения

- Встроенная локальная OCR-модель (RapidOCR) обучена преимущественно на
  печатном тексте — рукописный русский распознаётся слабо. Слабые
  результаты автоматически попадают в очередь ручной проверки; улучшенную
  модель можно подключить через интерфейс провайдера без изменения кода.
- По умолчанию облачные сервисы распознавания отключены и данные не
  покидают компьютер (включаются явно в настройках приватности).
